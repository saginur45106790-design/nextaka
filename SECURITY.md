# Reporting a vulnerability

Do not post credentials, payment evidence or personal records in a public issue.
The operator must configure and publish a monitored security contact before launch.
Until then, use a private GitHub Security Advisory if enabled for this repository.
Include affected version, a minimal reproduction using test accounts, impact and
suggested mitigation. Do not probe production financial accounts without consent.

See docs/SECURITY.md for implementation controls and docs/RELEASE_STATUS.md for
verification limits. This repository has not received an independent security audit.
